# MODULE SPARK-03: THE MEMORY TITHE ALTAR OF THE FEY COURT

### 1. Mythic Transaction Design

A non-combat social encounter where the cost of passage is measured not in coin or blood, but in identity.

* **The Sylvan Altar:** A hollow carved oak heart-tree filled with shimmering, liquid memory-mist.
* **The Guardian's Demand:** To cross the sylvan border without triggering the Iron-Thorn living barrier (`ECOL-03`), each party member must kneel, place their forehead against the wood, and allow a single true memory to be excised from their mind.
* **The Repository:** The Fey collect human memories to experience mortality, grief, and romantic longing, which their immortal natures lack.

### 2. GM Placement & Player Roleplay
* **The Sacrifice:** Players must verbally state which specific memory their character is surrendering. If a player offers a trivial or fake memory, the tree thorns snap shut, pinning their hand.
* **Retrieving Memories:** Memories drift in the tree as glowing glass orbs. A thief can attempt to steal an ally's stolen memory back, but doing so risks drawing the wrath of the entire sylvan court.
