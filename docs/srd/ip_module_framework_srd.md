## 1. Executive Mission & System Boundaries

The **IP Module Framework** is the universal Rosetta Stone of Creator Studio. It provides an infallible, system-agnostic translation protocol that converts **any Intellectual Property, historical period, fictional universe, or legacy tabletop RPG module** into self-contained, interoperable pointcrawl modules.

Whether translating:
* **Real History** (e.g. The Crossing of the Rubicon, The Bronze Age Collapse, The French Revolution),
* **Shonen Anime & Pop Culture IPs** (e.g. *Dragon Ball Z*, *Warhammer 40k*, *Cyberpunk*, *Fallout*), or
* **Legacy Tabletop RPG Modules** (e.g. *Curse of Strahd*, *Keep on the Borderlands*, *Tomb of Horrors*),

the IP owner does not write prose adventures or system-locked stat blocks. Instead, they translate narrative elements into **functional topological components**:
1. **Pipeline Tier Classification** (Tier 1 Macro Governance through Tier 5 Climax Engines).
2. **Pointcrawl Spatial Anchors** (Node topology, Hub Eligibility, and Adjacency Tethers).
3. **Sociological Competing Values & Tarot Affinity** (Hierarchy, Clan, Market, Adhocracy).
4. **Typed Resource Contracts** (`provides: [...]` and `requires: [...]` tags).
5. **Universal Threat Clocks & 4-Level Dials** (Light, Moderate, Severe, Lethal consequences).
6. **4-Corner Dramatic Opposition Webs** (Establishment, Opponent, Shadow, Outcast).
7. **Standalone Fallbacks** (Zero-blockage runtime isolation).

## 3. Topographical Pointcrawl Integration & Hub Eligibility

Modules socket into nodes within a 22-node pointcrawl network. The IP author must specify how their module behaves topographically.

### 3.1 Hub Eligibility Archetypes
* **`candidate`**: Standard urban center, castle, fortress, or major village. Capable of winning Tarot wave elections to become one of the 5 regional **Sovereign Hubs**.
* **`never`**: Topologically ineligible to become a hub (e.g. hazardous caves, animal reserves, transit highways, secret sanctuaries, planar rifts). Always operates as a dependent **Satellite/Outpost**.
* **`always`**: Guaranteed anchor hub (e.g. Imperial Capital, Megacity Core, High Citadel). Automatically claims one of the 5 Sovereign Hub slots and smothers adjacent nodes.

### 3.2 Directional Influence Tethering
Modules interact along pointcrawl edges via two connection modes:
* **1-Way Influence ($u \to v$)**: Asymmetric feed. An upstream quarry, water reservoir, or broadcast tower influences a downstream bastion, but receives no return feedback.
* **2-Way Mutual Influence ($u \leftrightarrow v$)**: Reciprocal trade corridors, mutual defense pacts, or cultural twin-cities.

## 4. Sociological Matrix & Culture Quadrants

Every IP community operates within the **Competing Values Framework** (CVF), mapping to one of four fundamental organizational cultures:

```text
                  COLLABORATE (Internal)
                     CLAN [Green]
                          │
  CREATE (Flexible)       │       CONTROL (Stable)
  ADHOCRACY [Blue/Red] ───┼─── HIERARCHY [White]
                          │
                     MARKET [Black]
                   COMPETE (External)
```

1. **Hierarchy (Control / White)**: Order, bureaucracy, legion discipline, quarantine law, legal precedent, central magistrates.
   * *Examples*: The Roman Senate, Frieza Force Command, The Burgomasters of Barovia.
2. **Adhocracy (Create / Blue/Red)**: Innovation, arcane science, rebel skirmishers, outlaw freeholds, rapid tactical adaptation.
   * *Examples*: Roman Optimate deserters, Capsule Corp inventors, Order of the Feather wereravens.
3. **Market (Compete / Black)**: Ruthless commerce, extortion tolls, mercenary contracts, black-market contraband, extraction quotas.
   * *Examples*: Publicani tax-farmers, Planetary Broker Syndicates, Vistani trade caravans.
4. **Clan (Collaborate / Green)**: Kinship ties, tribal elders, mutualist barter, sacred memory, ancestor veneration.
   * *Examples*: Plebeian neighborhood collegia, Namekian Agricultural Villages, The Mountain Fanes of Barovia.

## 5. Typed Resource Tag Contracts

To enable automated supply chain validation in Campaign Studio, modules declare explicit inputs and outputs using the format `[Category]: [Specific-Asset-Name]`.

```yaml
provides: ["Power: Pelton-Arc-Surge", "Material: Refined-Silver-Ingots"]
requires: ["Material: Raw-Quartz-Ore", "Labor: Indentured-Work-Gangs"]
```

### 5.1 Standardized Categories
* **`Power`**: Arc electricity, hydraulic waterflow, nuclear cores, ki/magical conduit batteries.
* **`Material`**: Timber, iron ore, silver bullion, alchemical sulfur, vibranium, Dragon Balls.
* **`Bio`**: Grain bushels, fungal spore broth, medical salves, blood serums, wine reserves.
* **`Tech`**: Scouter sensors, shortwave radios, mechanical dynamos, siege ballistic engines.
* **`Authority`**: Judicial warrants, imperial seals, planetary clearance codes, priestly edicts.
* **`Labor`**: Skilled guild smiths, peasant levies, penal work crews, android servitors.
* **`Climax`**: Eschatological catalysts, planetary detonators, planar collider keys.

## 6. Tabletop Runtime Architecture

Modules must provide concrete, immediate runtime tools adhering to the [Universal Adventure Framework SRD](file:///c:/Users/Milo/Documents/Antigravity/Creator/docs/srd/adventure_framework_srd.md).

### 6.1 The 4-Level Output Dial
The module must define how its core engine scales across 4 intensity levels:
* **Level 1 (Dormant / Routine)**: Baseline passive state. Low difficulty checks (**Light Tier: DC 10 / 1d6 damage**).
* **Level 2 (Operational / Supervised)**: Default active throughput. Moderate friction (**Moderate Tier: DC 13 / 2d8 damage**).
* **Level 3 (Overdriven / Crisis)**: Surge production or public discovery. Dangerous fallout (**Severe Tier: DC 16 / 4d10 damage**).
* **Level 4 (Catastrophic / Eschatological Meltdown)**: Total containment breach or collapse (**Lethal Tier: DC 20 / 8d12 damage**).

### 6.2 Threat Clocks
Every dynamic module provides 1 to 3 visual segmented **Threat Clocks**:
* **4-Tick (Tactical / Imminent)**: Immediate crisis (e.g. Scouter Alarm [ ][ ][ ][ ]).
* **6-Tick (Environmental / Node-Wide)**: Medium-scale escalation (e.g. Senate Martial Dictatorship [ ][ ][ ][ ][ ][ ]).
* **8-Tick (Macro / Climax)**: Planetary/regional catastrophe (e.g. Namek Core Meltdown [ ][ ][ ][ ][ ][ ][ ][ ]).

### 6.3 4-Corner Dramatic Opposition Matrix
Every narrative situation is structured as a 4-corner web of conflicting motives:
1. **Establishment (The Power)**: The entrenched authority defending the current order.
2. **Main Opponent (The Challenger)**: The active revolutionary, invader, or warlord seeking disruption.
3. **Thematic Shadow (The Profiteer)**: The corrupt merchant, mercenary, or parasite exploiting the clash.
4. **Tertiary Outcast (The Victim / Pariah)**: The collateral bystander, forgotten minority, or subterranean exile caught in between.

## 7. Standalone Fallback Invariant

Every module **must** function if dropped into an isolated one-shot or if connected pointcrawl edges are severed. The IP author must include a **`standalone_fallback`** narrative clause explaining how the node sustains itself without external supply chains (e.g. emergency generator reserves, foraging local mineral moss, or local authoritarian martial law).
