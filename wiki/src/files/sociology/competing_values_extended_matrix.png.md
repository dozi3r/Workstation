### Quadrant Deconstruction
* **Clan (Human Relations Model)**: Value drivers include commitment, communication, development; Leader archetype: *Mentor / Facilitator*.
* **Adhocracy (Open Systems Model)**: Value drivers include innovation, cutting-edge outputs, transformation; Leader archetype: *Visionary / Entrepreneur*.
* **Market (Rational Goal Model)**: Value drivers include market share, speed, competitive advantage; Leader archetype: *Hard-Driver / Producer*.
