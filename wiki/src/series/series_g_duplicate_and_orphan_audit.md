# Series G: Repository Hygiene Audit: Build-Time Mirrors, Legacy Scratch & Orphan Remediation

> [!WARNING]
> **Cross-Cutting Analytical Series**: Comprehensive forensic catalog, provenance analysis, and remediation roadmap ([[Ticket:SYS-AUDIT-01]]) for build-time file mirrors, overlapping specification drafts, stale simulation outputs, unreferenced diagrams, and `.scratch/` legacy tooling.

## 1. Architectural Context & Single Source of Truth Invariant

Ground Rule #2 of [[File:AGENTS.md]] establishes the **Single Source of Truth Invariant**: every topological graph, Tarot deck, sociological matrix, and worldbuilding module must have a single canonical authority on disk, while downstream HTML distributions are compiled deterministically via [[File:Build-Suite.ps1]].

During the full repository inventory conducted for the **Technical Manual & Bidirectional Codebase Wiki**, [[File:wiki/build_wiki.js]] scanned every file in the workspace and cross-referenced byte hashes, compiler write targets, and inbound link graphs. That audit (codified in [[File:tickets/system/SYS-AUDIT-01_duplicate_mirror_and_orphan_file_remediation.md]] and building upon the earlier [[File:docs/audit/2026-10-creator-studio-audit-dossier.md]]) identified **four distinct categories of duplicate mirrors, overlapping drafts, stale outputs, and legacy `.scratch/` scripts**.

To protect backwards compatibility prior to destructive file deletion, [[File:wiki/build_wiki.js]] maintains an explicit `AUDIT_FLAGS` registry (lines 224–300) that automatically badges every affected file's wiki page and generates bidirectional links to its canonical counterpart and [[Ticket:SYS-AUDIT-01]].
