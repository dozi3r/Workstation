Architectural Role & Subsystem Context

docs/AI_DEVELOPER_GUIDE.md is the Authoritative Engineering Manual for Autonomous AI Agents & Human Developers within Volume I: System Architecture, Governance & Ontology. While 📄 AGENTS.md serves as the concise root router, docs/AI_DEVELOPER_GUIDE.md provides the deep technical specification for modifying the modular Workstation codebase (src/workstation/), governing the Scale-Fluid Hierarchical Cartography engine, the Global State Swap Adapter, the In-App Bidirectional Wiki & Citation Lexer, and IndexedDB Multi-Map Persistence.

It is a core authority for 🧭 Series B: Scale-Fluid Hierarchical Cartography, Global State Swap & IndexedDB and 🧭 Series E: Zero-CORS Offline Bundling, Compass Headers & Self-Updating Wiki Architecture.

Core Invariants & Architectural Contracts

  • 1. Modular Source Invariant (src/workstation/): Never edit 📄 start.html directly. All feature work must target the modular scripts inside 📄 src/workstation/template.html and src/workstation/scripts/*.js, followed by executing 📄 Build-Suite.ps1.
  • 2. The Global State Swap Pattern (state_adapter.js):
  • Live global variables (nodes, links, waves, drawnCards, sovereignHubs, sovereignHubTarget, smotheredNodes, nodeSlottedModules, edgeSlottedModules, revealedNodes, activeMapMetadata) represent the currently viewed map.
  • syncActiveMapToRegistry() in 📄 src/workstation/scripts/state_adapter.js packs live globals into maps[activeMapId].
  • switchActiveMap(targetMapId) synchronizes the outgoing map, swaps activeMapId, unpacks maps[targetMapId] into the live globals, loads the map raster from IndexedDB via 📄 src/workstation/scripts/map_store.js, and triggers recalculateBalancing(), renderCanvasGraph(), updateBreadcrumbsHUD(), and buildWikiIndex().
  • 3. 7-Tier Scale-Fluid Cartography: Any map can be a root map or attached as a child map (node.childMapId = "map_id") across 7 descriptive tiers (cosmic, continent, region, settlement, district, building, floorplan), supporting top-down drill-down, bottom-up wrapping (reparentMap()), and lateral independence.
  • 4. IndexedDB Schema v2 (CreatorStudioMapDB): Managed by 📄 src/workstation/scripts/map_store.js, storing binary/DataURL raster backgrounds in object store active_map keyed by id: mapId (with transparent fallback to legacy key "active_map" for map_root).

Data Flow & Subsystem Integration Matrix

docs/AI_DEVELOPER_GUIDE.md maps the collaboration across the modular Workstation source files:

  • 📄 src/workstation/scripts/state_adapter.js — SCALE_TIERS, maps registry, syncActiveMapToRegistry(), switchActiveMap(), createMap(), attachChildMapToNode(), reparentMap().
  • 📄 src/workstation/scripts/map_store.js — CreatorStudioMapDB v2 IndexedDB persistence (loadPersistedMapFromDB(), listPersistedMapsFromDB()).
  • 📄 src/workstation/scripts/map_navigator.js — Breadcrumb HUD (#canvas-breadcrumbs-hud) and Map Tree modal (#map-navigator-modal).
  • 📄 src/workstation/scripts/wiki_engine.js — Token lexer ([[Node:id]], [[Node:mapId/id]], [[Map:mapId]], 📦 modId, [[Faction:id]], [[Corridor:u-v]], @EntityName), buildWikiIndex(), getBacklinksForEntity(), and attachWikiAutocomplete().
  • 📄 src/workstation/scripts/canvas_hud.js — Concentric cyan portal ring rendering for nodes with childMapId, double-click drill-down, and Escape key parent ascent.
  • 📄 src/workstation/scripts/entity_manager.js — Entity architecture (NPCs, quests, items, dials) stationed on active nodes.
  • 📄 src/workstation/scripts/stage_6_export.js — Multi-map JSON preset serialization and transparent single-map legacy import upgrade.
  • 📄 src/workstation/template.html — Master HTML shell containing @@INCLUDE@@ and @@INJECT@@ markers consumed by 📄 build_suite.js.
