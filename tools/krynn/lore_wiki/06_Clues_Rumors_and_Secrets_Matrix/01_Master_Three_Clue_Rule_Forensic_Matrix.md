# Master Three-Clue Rule Forensic Matrix

*Consolidated Investigation Bible & Multi-Vector Forensic Matrix for 29 Campaign Mysteries*  
**Setting Horizon:** Age of Despair (326 AC) through War of the Lance Climax (352 AC)  
**Methodology:** Justin Alexander’s *Three-Clue Rule* (For every conclusion the players must reach, seed at least three independent clues: (a) Social Access / Interrogation, (b) Physical Forensics / Environmental Clues, (c) Oral Lore / Tavern Rumors, backed by (d) Social / Skill Leverage Protocols).

## 1. Investigation Architecture & The Three-Clue Rule

In a complex, multi-theater campaign like the War of the Lance, investigative paralysis can derail tabletop pacing. Players routinely miss clues, misinterpret forensic evidence, or kill informative NPCs. 

To ensure robust campaign flow:
```
+----------------------------------------------------------------------------------------------------+
|                                THE THREE-CLUE RULE OPERATIONAL ENGINE                              |
|                                                                                                    |
|    [CLUE VECTOR A: SOCIAL ACCESS]               [CLUE VECTOR B: PHYSICAL FORENSICS]                |
|    - Eyewitness confessions                     - Architectural blueprints                         |
|    - Prisoner interrogations                    - Chemical residues & scorch marks                 |
|    - Diplomatic parleys                         - Autopsies & material relics                      |
|                           \                   /                                                    |
|                            \                 /                                                     |
|                             v               v                                                      |
|                              CAMPAIGN MYSTERY                                                      |
|                             ^               ^                                                      |
|                            /                 \                                                     |
|                           /                   \                                                    |
|    [CLUE VECTOR C: ORAL LORE & RUMORS]          [LEVERAGE PROTOCOL: MECHANICAL BYPASS]             |
|    - Tavern gossip & soldier songs              - Intimidation / Persuasion checks                 |
|    - Bardic ballads & local proverbs            - Spells (Detect Magic, Zone of Truth)             |
|    - Old wives' warnings                        - Class features (Thieves' Cant, Tracking)         |
+----------------------------------------------------------------------------------------------------+
```
